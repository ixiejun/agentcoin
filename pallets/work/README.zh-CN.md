# pallet-work

付费推理的结算（MVP 技术方案 §5.4，refine / accumulate；决策 D2：奖励只给被使用、有人付费并通过验证的工作）。提供者与网关对每次请求各签一条收据（`ac_primitives::market::receipt`）；收据由网关在链下保存，prompt 和输出从不进入收据。链上只看到工作报告并完成资金划转。

## 工作报告

由已登记的网关（活跃或退出中）调用 `submit_report(root, receipt_count, entries, vouchers)`：

| 部分 | 规则 |
|---|---|
| `root`、`receipt_count` | 收据的 Merkle 根（`ac_primitives::market::receipt_tree`）；收据条数至少为汇总项数。 |
| `entries`（1–256 项） | `(任务类型, 提供者, 模型, 美元, 输入 token 数, 输出 token 数)`；只接受推理；同一（提供者, 模型）不得重复；提供者已登记、未禁闭且价格列表中有该模型。 |
| `vouchers`（1–64 张） | 经 `Credit` 接口（D20）兑付到**网关账户**；每个通道一张。 |

汇总项的美元之和必须**等于**这批凭证兑付的美元增量：网关只能把用户的钱分给提供者，除网关费外不能留下任何部分。一张凭证无效，整份报告被拒绝。必须已设置参考汇率。

## 分配

`G` = 兑付额 + 短缺（托管不足的部分；网关用自己的可用余额支付，因此网关要保持高于存在性押金的可用余额）。全部为整数运算，向下取整：

```text
销毁     = G × b                  （b = 20%，经 Emission 销毁）
网关费   = G × 网关费率           （不超过 5%）
提供者池 = G − 销毁 − 网关费
份额_i   = 提供者池 × usd_i / Σ usd（取整余数也销毁）
工作量_i = (G × usd_i / Σ usd) × k（k = 0.5；k − b ≤ 0.5，研究 03 §1.5）
```

份额与网关费**冻结在网关账户上**（冻结原因 `Pending`），直到挑战期结束；链上按（收款人, 到期纪元, 网关）记账。

## 挑战期与领取

在排放纪元 `s` 提交的报告于 `s + C` 到期（`C` = 2 个纪元）。其工作量计为该纪元的已核验市场工作量：`Emission` 把 `min(50% × avail, 工作量)` 铸入本模块的领取账户并回报（`MarketPayout::settled`）。之后任何人都可以调用 `claim(who, [(纪元, 网关), …])`（至多 64 项）：份额从网关转给 `who`，网关自己的网关费解冻，`who` 在该纪元的排放份额 `market × 工作量 / Σ 工作量` 从领取账户转出。如果 `who` 的可用余额加上款项仍低于存在性押金，整次领取失败。领取账户永久留存一个存在性押金（取自它收到的第一笔排放），因此领取不会把它清空。

M5 没有任何交易可以对报告提出争议或将其作废。审计（M6）通过 `pallet-providers` 禁闭作弊的提供者；提供者在其工作量被结算前被禁闭时，这些工作量立即失效（该纪元的已核验工作量相应减少），其冻结的份额在被领取时销毁。网关的网关费从不随提供者一起作废。

## 参数

| 参数 | 活链 | dev / local |
|---|---|---|
| `burn_bps`（`b`） | 2,000 | 2,000 |
| `emission_bps`（`k`） | 5,000 | 5,000 |
| `challenge_epochs`（`C`） | 2 | 2 |
| `retention_epochs` | 720（30 天） | 20 |

创世时拒绝：`b` 不在 1,000–9,000 之间、`k − b` 超过 5,000、挑战期或保留期为 0。报告在到期 `retention_epochs` 个纪元后被清理（每次提交至多清理四份）；待领取款项不随之删除。

## 功能开关

| 开关 | 默认 | 用途 |
|---|---|---|
| `std` | 是 | 原生构建与测试。构建 WASM runtime 时关闭。 |
| `runtime-benchmarks` | 否 | 两个调用在上限处的基准（64 张 ML-DSA-87 凭证、256 个汇总项；64 个领取项）。 |
| `try-runtime` | 否 | SDK 的 try-runtime 支持。 |

## 示例

```rust
use ac_primitives::market::MicroUsd;
use ac_primitives::market::work::allocate;

// 结算 1 美元（每美元 10^6 个最小单位时为 10^6 个单位），b = 20%，网关费率 5%，k = 0.5，
// 两名提供者分别服务了 0.75 与 0.25 美元。
let a = allocate(1_000_000, 2_000, 500, 5_000, &[MicroUsd(750_000), MicroUsd(250_000)]).unwrap();
assert_eq!(a.burn, 200_000);
assert_eq!(a.gateway_fee, 50_000);
assert_eq!(a.shares, [562_500, 187_500]);
assert_eq!(a.work, [375_000, 125_000]);
```
