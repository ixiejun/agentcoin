# market/model-registry Specification

## Purpose
规定推理市场的模型登记：模型 ID 如何由权重清单确定、谁可以登记、血缘声明与预留字段、登记押金，使网关、提供者与审计者对“同一个模型”有唯一、可复算的标识。

## Requirements

### Requirement: 模型 ID 由权重清单确定
模型 ID SHALL 是对规范化权重清单做带域分离的 256 位 BLAKE3 哈希，哈希上下文为 `agentcoin 2026-09 model-id v1`。权重清单由模型名称、架构名称、量化方式和按顺序排列的各权重分片的 32 字节哈希组成，其规范编码在设计中固定，并有测试向量。模型 ID 由链根据登记时提交的清单计算，登记者不能自行指定。任何人 SHALL 能用同一清单在链下复算出相同的 ID。

#### Scenario: 链下复算
- **WHEN** 登记一个清单后，用仓库提供的工具对同一清单在链下计算模型 ID
- **THEN** 两者相同，且与设计中的测试向量一致

#### Scenario: 分片顺序影响 ID
- **WHEN** 两个清单只有分片哈希的顺序不同
- **THEN** 两者的模型 ID 不同

### Requirement: 无许可登记与去重
任何已登记公钥的签名账户 SHALL 能登记模型，无需许可。同一模型 ID 只能登记一次，重复登记 MUST 失败。清单的各字段 MUST 有上限（名称、架构不超过 128 字节，分片不超过 1,024 个），超出即失败。量化方式 SHALL 取自固定枚举（至少包括 BF16、FP16、FP8、INT8、INT4），编号一经发布不再更改。

#### Scenario: 重复登记
- **WHEN** 两个不同账户先后登记同一清单
- **THEN** 第一次成功，第二次失败，登记记录中的登记者为第一个账户

#### Scenario: 超出上限
- **WHEN** 登记一个包含 1,025 个分片哈希的清单
- **THEN** 登记失败

### Requirement: 血缘声明
登记时 MAY 声明一个父模型及派生方式（至少包括微调、量化、蒸馏、合并）。父模型 MUST 已登记，且不能是模型自身；未登记的父模型使登记失败。血缘只是声明，协议不验证其真实性（D28）。许可证标签 SHALL 仅作展示，协议不据此限制任何行为（D6）。

#### Scenario: 父模型不存在
- **WHEN** 登记时声明的父模型 ID 从未登记
- **THEN** 登记失败

#### Scenario: 声明量化血缘
- **WHEN** 先登记一个 BF16 模型，再登记它的 INT4 版本并声明父模型为前者、派生方式为量化
- **THEN** 两次登记都成功，查询后者可读到该血缘

### Requirement: 预留字段
模型记录 SHALL 包含为全量版预留的版税字段（D22）。本阶段该字段必须为空，登记时填写版税 MUST 失败。

#### Scenario: 填写版税
- **WHEN** 登记时带上版税设置
- **THEN** 登记失败，并报告该功能尚未启用

### Requirement: 登记押金与不可修改
登记 SHALL 冻结登记者的一份存储押金，金额按记录的条目数与字节数计算（与合约存储押金相同的公式：每条目 0.01 ATC，每字节 0.0001 ATC）；余额不足时登记失败。模型登记后其清单与血缘 MUST NOT 被修改；本阶段模型记录不可删除，押金保持冻结。押金是冻结而非转账或销毁，不改变总发行量。

#### Scenario: 押金冻结
- **WHEN** 账户登记一个模型
- **THEN** 该账户的可用余额减少押金额、冻结余额增加相同数额，总发行量不变

#### Scenario: 余额不足
- **WHEN** 可用余额低于押金的账户登记模型
- **THEN** 登记失败，余额不变
